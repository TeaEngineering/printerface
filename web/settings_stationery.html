Stationery

The PDFs for a document are drawn when it arrives, and kept. When Printerface starts it reuses them rather than drawing them all again, so a change to the stationery (stationery.py, or the company details and logos under [Stationery] in ~/printerface/email.cfg) does not reach documents that have already been drawn until you draw them again here.

% if redrawn is not None:
Drew ${redrawn} document${'' if redrawn == 1 else 's'} again.
% endif % if stale:

${stale} of the ${total} loaded documents were drawn under older stationery.

The server is busy while this runs, about a second for every few hundred documents.
% else:
